[# 🚗 Smart Parking System

A web application for **parking reservation, payment processing, and parking management**, built with **ASP.NET Core MVC** following the **Controller → Service → Repository** architecture.

> **Note:** This repository contains the **source code and project documentation only**. The original university database, deployment environment, and credentials are not publicly available.

> 🎓 This project was originally developed as part of the **Object-Oriented Analysis and Design** course at the **Faculty of Electrical Engineering, University of Sarajevo**.
>
> 🔄 After the course was completed, the project was independently **refactored and improved**, introducing the **Controller → Service → Repository** architecture to improve code organization, maintainability, and separation of concerns.

---

# ✨ Features

## 👤 User

- ✅ Register and log into the system
- 🔍 Browse available parking spaces
- 🎯 Search and filter parking spaces
- 📅 Create parking reservations
- ✏️ Modify existing reservations
- ❌ Cancel reservations
- ⏳ Extend reservation duration
- 💳 Complete online payments
- ⭐ Leave parking reviews

---

## 👨‍💼 Operator

- 🚘 Manage parking availability
- 📊 Monitor reservations
- 🅿️ Update parking space status

---

## 👨‍💻 Administrator

- 👥 Manage users
- 🗺️ Manage parking zones
- 🚗 Manage parking spaces
- 📈 Monitor system activity
- ⭐ Manage user reviews

# ⚙️ Getting Started

## Prerequisites

- Visual Studio 2022 or newer
- .NET 8 SDK
- SQL Server / LocalDB

---

## Installation

Clone the repository:

```bash
git clone https://github.com/sarabajric/SmartParkingSystem.git
```

Then:

1. Open the solution in **Visual Studio**.
2. Restore the **NuGet packages**.
3. Configure the database connection in **appsettings.json**.
4. Run the Entity Framework Core migrations.
5. Build and run the application.
